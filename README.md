# Circlely Demo

A polished, frontend-only community platform demo inspired by the supplied Apna Circle reference screenshots.

## Stack

- React
- Vite
- Framer Motion
- Lucide React
- CSS with responsive breakpoints

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes

Circlely is an original fictional brand and implementation. It does not use the Apna Circle logo or imply affiliation with Apna Circle.

The demo includes:

- animated hero social network
- interactive circle explorer
- people network
- activity cards
- community pulse
- dark CTA/statistics section
- safety cards
- animated how-it-works timeline
- testimonial carousel
- about section
- FAQ accordion
- Join Circle modal
- responsive mobile navigation
- reduced-motion support

All product interactions are frontend demo interactions; there is no backend or real authentication.
